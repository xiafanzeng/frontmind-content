# FrontMind v4.11.8 修改记录

发行版本 4.11.8；Runtime 4.11、Reference Pack 格式 4.1 不变。宿主 XTY gpt-6-astra/high，作者 DeepSeek Pro/max 不变。

- 原蓝图动作增加简短 article_brief，并将 example_use 与完整例文一起传入作者和编辑。表达任务说明重点、关系和详略，不预写起句、转场或结尾。
- 共享作者规范合并重复约束，以叙述主次、事实关系和阅读推进作为成稿目标。素材不按章节铺成底稿，所有类型继续保留自身表达任务。
- E8 和宿主在现有调用内先通读篇章，再调整段落，最后复核表述和事实。事实正确或能够读懂本身不足以证明达到本篇体裁要求。
- 同次标题调用返回 canonical_title_id。P0从媒体品宣组选择发布题，取消默认取第一项；选定题独立成立，不依靠未发布副题补充必要条件。
- 标题使用独立媒体标题编辑角色：20项均为同一整篇文章的可替换发布主标题，旧H1仅标识待替换版本；组别不改变报道范围，每项只生成title，保持旧h1读取兼容。仅标题请求与对应缓存受影响。
- 发布稿只替换宿主终稿首H1。原始宿主稿、标题结果和派生稿分别保存并绑定来源，Word、HTML、Markdown、标题映射与Reference Pack保持一致。
- 历史已完成任务可读，新的合同和Prompt使受影响缓存失效；保留原始结果、一次宿主修正上限、业务确认路径和无图交付。

独立作者对照保留相同输入、实际响应和分阶段全文，不改变生产默认路由。合成样本不作为真实客户或全行业覆盖证明；客户正文与验收材料不进入通用运行包。

本文件描述实现范围。程序、真实 API、内容与文档验收分别记录，测试通过不代表文采已通过。
