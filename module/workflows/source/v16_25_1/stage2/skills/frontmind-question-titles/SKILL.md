# 问题文章标题

先连续读完整定稿，明确这篇回答什么问题、针对什么读者、介绍哪些主体和用途。标题必须与该中心对应，不把章节小题包装成全篇标题。

把本题同观察期的全部Top20标题作为表达风格池，逐项判断与本篇写法的关系，同类在前，保留全部候选。独立自动选两个最接近本篇的核心标题参考，记录题式、语序、范围和理由；与正文两篇构思参考分开。没有完全同类型的样本时明确记录近似，不捏造单品牌例文。引用排名决定候选池，不代表标题质量。

拟题同样遵守所有写作共用的“自然语言资料＋简要委托”规则，不是JSON写作例外。对应材料是当前问题、完整正文和完整标题例文；研究、排序、状态及提交合同的JSON只留内部。

作者输入有三部分：全部已排序标题及两条核心参考、当前问题与精简委托、当前完整正文。本Skill作为拟题职责一起提供。`gemini-4-argon` high先拟10题，Kimi Hosted high只检查文字通顺、重复和是否明显偏离全文主题，并选推荐项；保留Gemini原标题和顺序。有具体文字问题才交Gemini轻润色一次，之后只确认原问题的处理，保存原始与必要修改记录。

十题是同一篇的可替换主标题。允许有价值的同义与适度侧重差异，不强制十个传播主题或5+5分组。每题让读者清楚文章的对象和用途，能自然回应当前问题。推荐稿可以明确推荐意味；不因为怕表达相似而全部改成“如何选择”，也不机械复制问题全文。

沿用当前正文的原意、名称、数字、条件与主张口径；这些是文字编辑边界，不是新的事实核验任务。不回查知识库、不联网查证、不索要来源，也不重审已确认优势或正文内容。品牌名称是否进入标题服从用户和本篇任务，不预设统一禁用。标题参考只供表达借鉴，不把其中的新年份、排名、资质、数据或经历写入本篇标题。

作者API直接输出1—10编号标题，每行一个，不用JSON包裹，不强制附角度和理由。Kimi核对通过后可在内部结果中保存title及简短核对说明，angle/reason可为空，并推荐一个序号。标题独立交付，不自动改写正文主标题。不要用评分、AI率或禁词清零替代实际编辑。

## v16.17类别继承

以已确认的产品用途和本篇positioning_scope为范围。全部Top20保留，关系同时考虑文章写法与产品类别；核心两条不选明确跨用途标题。混合或邻近题式说明借鉴边界，不移植事实和医疗/录取等承诺。正文候选池扩展不会改变原Top20标题池。

关键产品类型以selected_category.product_boundaries为准，机构/家庭等场景不能代替该边界；标题不把非医疗健康评估改成临床诊疗能力。本包只为当前已选模式、已选主体的文章拟题，不另行增加推荐主体。
