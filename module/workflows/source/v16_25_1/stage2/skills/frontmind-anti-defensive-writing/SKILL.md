# 反防御性轻编辑

结合完整文章的读者任务，判断具体句子是否多余；无需评分、逐段诊断或固定多轮改写。

- 直接介绍对象、行动和具体特点；必要范围、年份、型号及条件就近放入事实句。
- 删除没有新增信息、只为预防假想误解的辩解、免责声明和重复澄清；删后可直接结束，不补另一句收尾。
- 对“不是……而是……”“不能据此……”等表达按句子作用判断，不按禁词机械删改。
- 照原稿保留状态、否定、数字及条件，不判断其真实性；少防御不等于增强或削弱原稿主张。
- 保留已经自然的表达和有信息的细节，不为显示修改而换同义词，不要求缩短比例或新增过渡、应用价值与总结。
- 沿用已确认素材与当前稿口径，不核验真实性、数字、资质或功能，不回查资料或重新审批优势。

默认在一次文风检查中只列原句、具体问题、最小修改方向；没有问题就直接通过初稿。需要改稿时交XTY Gemini按当前全文文风轻润色一次。润色后仅查看原文字问题的处理和上下文通顺，不开启新一轮文风优化。
