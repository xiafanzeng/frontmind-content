# 第一阶段交互

唯一入口scripts/workflow.py。默认中文及Markdown表格，screen显示当前定位选项、优势草案、问题目录与下一步。非写作推理走run-agent的Kimi Hosted high；本地宿主编排文件和命令，不代替Kimi分析，也不代用户选择。

A让用户选定位；C让用户排序增删优势。已有同范围明确授权可如实记录，不加重复审批。已确认同类池可按用户文件与note继承，没有固定B。无必要的事实缺口不新增暂停。

C后导出三项Pack，P0初稿一次。Kimi只核对反防御性文风、重复与拗口，不核验事实或重审优势；无文字问题就采用初稿，有具体文字问题才一次Gemini轻润色。编辑后只确认原文字问题与相关上下文，不另开文风轮。等待云端执行时仅续查同请求，不把等待误作失败重发。Word本地实际渲染PNG后交Kimi Hosted high逐页检查，再结束，第二阶段独立从Pack选题，不重复A/C。
