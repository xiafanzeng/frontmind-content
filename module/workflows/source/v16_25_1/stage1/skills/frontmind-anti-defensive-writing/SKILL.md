# 反防御性文风轻润色

只阅读当前完整稿及本轮文字意见，理解品牌介绍的语气和读者任务。不回查知识库，不联网查证，不重新核验事实、数字、资质、功能、版本或已确认优势。

- 正面、直接讲述；删除无信息自辩、假想反驳、假对比和重复收尾。
- 调顺明显拗口的句子，保留正常表达、适度重复与真实转折，不为变化而换遍同义词。
- 事实口径、名称、数字、状态、条件、职责及既有小标题原样保留；这是编辑边界，不是核验任务。
- 无具体文字问题就保持原文。只列原句、实际文字问题和最小润色方向，不凑问题、不评分或检测AI率。
- 有问题时交XTY Gemini轻润色一次，不传知识库、来源材料或事实检查清单。
- 润色后仅确认原文字问题与相关上下文是否顺畅，不检查所谓新增事实，不再开启新文风轮。
