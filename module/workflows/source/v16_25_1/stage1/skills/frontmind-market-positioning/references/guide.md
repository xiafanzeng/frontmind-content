# 第一阶段定位说明（16.25.1）

输入为企业名称及完整Markdown知识库。Kimi Hosted high实际阅读主题节点和原资料，区分品牌、具体产品、软件、专业服务及版本，以用途、产品本质和客户任务给有依据的定位选项与优化问题。

A展示类别、用途范围、依据后等待用户具体选择。机构/家庭、形态、租赁等场景属性不自动替代产品本质；缺少某证件也不能反推出法定属性。没有监测数据不造提及率或排名，知识库不证明别家产品事实。

已明确确认的同类池可用confirmed-peers --file --by --note继承。只读“已确认同类竞品”章节或明确selected_candidates文件，不把材料中的厂商提及当确认。保留顺序、原来源和授权记录，不新增固定B暂停，不重做用户原有选择。确认的研究对象仍不等于其所有参数均已核实；第二阶段P02要按本篇选定子集及各自事实写作。

确认定位后在C整理并确认写作优势；新问题属于第二阶段，不触发重定位。程序只做合同及依赖校验，不把格式通过说成来源语义已被证明。使用真实Hosted artifact与请求记录，离线fixture不冒充模型研究。
