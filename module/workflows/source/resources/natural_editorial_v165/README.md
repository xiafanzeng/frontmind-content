# v16.5 自然全文编辑资源

`SKILL.md` 是随工作流固定加载的本地文字资源，用于初稿、全文编辑与返工。它不安装外部技能、不启动额外Agent、不调用评分或检测脚本。

本资源适用于P01至P06。已确认的主体、体裁和用户要求仍由原工作流入口负责；文风参考使用当前完整例文，文章池继续只用于构思。允许口语、有限重复和不完全工整的稿件感，是否需要再编辑以全文阅读效果判断。

三个上游技能的固定commit、许可证和方法采用范围见`sources.json`。humanizer-zh仅转述方法并自编规则及示范，不复制其正文；另两项为MIT。上游的学术语气、检测脚本、分数和门禁未集成，用户此次新闻品宣写作要求优先。
