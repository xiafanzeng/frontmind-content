# 品牌深度介绍的主标题

本篇是介绍一家企业或机构的品牌长文。读者读标题后，应当期待了解这家品牌的身份、业务特色与整体服务，而非某个项目的问答、选择攻略、流程教程或风险答疑。20题是同一篇成稿的替代主标题，不是20篇待写选题。

先通读全文，用一句内部概括确定企业身份与全文充分展开的品牌特点，不输出概括过程。围绕少数能统领全文的品牌角度拟题；角度可重复，表达应有真实区别。不按章节轮流抽取疾病、项目、单个医生、年份、限制或步骤凑题，不要求20种传播主题。

采用自然、完整的品牌陈述，让品牌名称与有实际内容的特点形成联系。可用品牌特写、机构介绍、业务版图、专业分工与服务特点等写法，但由全文决定，不能每题拼接同一模板。问句不是禁用词；本任务默认不用连续“为什么/如何/怎样”的问答入口。只有全文确实围绕一个品牌层面的疑问展开，且用户委托与这种形式一致时才用问句，不把一般介绍强装成探讨或调查。

正文里的面诊、费用告知、适用范围、不确定性与风险说明是对应事实的条件。保留它们对相关断言的约束，但不因为它们出现多次，就将“不承诺绝对效果”“先了解限制条件”“医生都有证吗”提升为整篇卖点。不把编辑要求（不夸大、不比较、资质具名）当成品牌价值；条件无法在标题中准确表达时，改选其他由全文支持的角度。

以具体业务和真实特点承载品宣，不用空泛的“重塑行业/定义未来/安全典范/领先标杆”。医院的等级、成立年份、资质与科室的归属必须分清；母院成立年份不自动等于科室成立年份，按三级标准规划不自动等于获得三甲资质。不得虚构品牌优势、行业地位、独家技术、客户体验、排名或疗效。不能因为正文有一句宽泛保证就把它放大成标题承诺。

每一题都放回整篇判断：它承诺的重点是否由全文主体支持？若把标题换成一篇鼻整形问答、面诊流程教程或风险说明仍完全贴切，而正文实际介绍整家机构，就重拟整题，不只加品牌前缀。准确不等于适合作为品牌主标题。

## 编辑动作示范（虚构品牌，仅用于学习写法，不提供事实）

正文确实介绍“明川软件”为制造企业提供生产协同产品，并展开研发、部署及服务团队：
- 不合适：为什么明川不承诺一周上线？
- 可用方向：明川软件：面向制造企业的生产协同服务
- 不合适：部署前先评估，明川怎样规避实施风险？
- 可用方向：从产品研发到项目服务，走近明川软件

正文确实介绍“青禾空间”的家居业务、设计与定制团队：
- 不合适：定制先量房再报价，青禾空间为什么坚持这一步？
- 可用方向：青禾空间：设计与定制相结合的家居服务

示范不是每题必用的“品牌：业务”公式。名称、特点和行业只取自本篇，不复制示范事实。

## 标题编辑与输出

作者只返回宿主规定的20项title/angle与canonical_title_id。angle用简短的品牌传播角度，不输出风险审查理由、后台边界、评分或检查报告。标题长度按自然阅读需要，不强制统一句长和标点，不机械禁词。

标题编辑收到原候选后，先用本篇体裁判断整组是否成立；候选整体像问题优化标题时，可以重拟全部20项，而不是只校对数字和事实。输出仍按原accepted/revised/incomplete合同：实际修改才报revised，不能把改题建议当作可交付标题。推荐项仅供用户选择，不写入正文。
