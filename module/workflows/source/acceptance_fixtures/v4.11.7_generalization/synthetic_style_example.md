# 合成文风示例：街角阅览室的一次调整
本例文专为写作方法测试虚构，不涉及真实机构和读者。只参考叙述方式，不移植事实。

## 把阅读留在离家近的地方
街角阅览室设在社区一层，临窗的长桌向街道展开，书架留在靠墙的位置。读者进入后先经过借还台，再到座位区；取书和落座的动线分开，工作人员可以在借还台处理登记，坐下阅读的人也不必频繁让路。

这次调整没有扩大书目。工作人员将常被问到的地方文献移到入口附近，为同一主题的书增加简短的索引卡。第一次来的人可以从卡片找到相邻书目，已有目标的读者则照原来的编号取书。两种查找方式在同一排书架上保留。

## 随借还记录调整开放安排
试行期间，阅览室把每周两个晚间时段延长一小时，并分别记录借还量和座位使用情况。下一轮开放时间将依据这些记录再作调整，目前仍沿用预约人数上限。
