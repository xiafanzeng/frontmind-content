# Final_v13 当前写作要求

新增写作要求合同 `frontmind-writing-requirements/4.13.2-final13`，正文执行合同继续使用 v12 的 XTY 意见分离与一次 DeepSeek 返工。v12 提示原样保留，新建任务启用 v13；旧完成稿通过新的蓝图/正文修改和 `--upgrade-writing-editor` 升级并保存完整快照。

本轮蓝图的 opening、sections、ending 与 example_use 作为可调整构思提供给作者、E8 和一次返工，补上此前只传事实与限制、丢失正面段落构思的问题。当前要求优先，章节可以合并、换序或舍弃，实际成稿不要求重排回旧蓝图。新建任务和显式新蓝图修改记录 `writing_outline_input_mode=suggested-outline-v1`；未标记的历史任务及其重试保留原输入，不增加写作步骤。

新建任务与显式新蓝图委托同时启用 `writing_mission_input_mode=editorial-mission-v1`。这一模式使用独立、精简的编辑职责，直接说明文章要完成的内容、事实归属与持续篇幅目标，不再从历史 `NATURAL_CORE`、`WRITING_FACTS_CORE` 逐句替换后叠加限制。作者输入集中为当前要求、可调整构思、选用事实及少量后台事实使用说明；出处索引只提供给需要查阅原件的阶段。事实素材直接写机构、项目、人员和服务，文件名、表格坐标及出处依据保存在来源字段。不同阶段继续使用同一明确篇幅目标，通过尚未展开的相关内容完成文章。

新模式的冻结请求标记为 `<frontmind_natural_editor version="4.13.2-editorial1">`。系统职责和蓝图字段说明按请求标记选择，历史标记继续使用原文本。已有 v13 任务通过正常的新蓝图修改入口启用，无须重复升级；更早版本仍按原升级入口处理。普通接受蓝图、重试、中断恢复、标题修改和局部正文修改均不自动切换。完成稿重新构思时，先验证旧稿并保存原任务快照，再启用新模式；正在运行的请求和原始模型输出保持原状。这项调整不增加模型调用、评分或确认页面。

在已启用独立编辑职责的任务中，后续新建的正文精修委托会在冻结记录中保存 `outline_input_mode=current-manuscript-v1`。这轮 E8、XTY 意见与一次返工从当前要求、实际完整稿、事实和本轮意见工作，不再注入早期蓝图的 opening、sections、ending 与 example_use，避免被已经删除的开头、旧栏目或统一结尾重新牵回。初次成稿仍参考蓝图构思；已有精修记录和中断恢复保持原输入，不自动加入该模式。

新正文精修可同时传入 `--writing-materials 文件或目录`，明确提供完整当前事实选材。JSON 沿用 `writing_material_markdown`、`material_adjustments`、`writing_material_sources` 三字段，后两项可为空。Markdown 将全文作为选材，使用说明和来源索引为空。目录只读取唯一的 `writing_materials.json` 或 `writing_materials.md` 入口，不拼接原始页面与研究记录。选材内容及哈希按 `explicit-writing-materials-v1` 保存在本次 revision，E8、P0 第三遍、XTY 和一次返工共享同一份事实；它整体替代旧蓝图的事实、使用说明和来源索引。下一次正文精修未传此参数时继承上一份冻结选材，显式传入才替换；标题修改不撤销它，重新委托蓝图则结束这段正文精修输入。原始来源仍使用已有补料入口保存，来源索引指向实际原件。程序不从历次编辑意见提取事实，也不自动把新补料全文灌入作者；历史请求无此字段时保留原输入。

未来新正文精修在冻结记录中同时保存 `editorial_review_scope_mode=actual-claims-v1`。只有明确带此标记的 XTY 阅读请求新增简短原则：事实修正针对正文实际断言；未作出的能力主张不补缺失说明；篇幅意见指向原件未采用的具体信息。作者仍可组织已知业务并说明与读者需求的关系，具体诊疗流程、手术能力和效果需要直接材料支持。既有精修与重试不自动加入标记，系统职责和已付费请求保持原文本；DeepSeek 与 XTY 分工、一次返工及随后标题流程不变。

完成稿同时提交新蓝图委托与例文时，先验证并保存旧任务快照，再摄取例文，最后生成一次新蓝图。已选 A 路线继续使用新例文；摄取失败或原 B 路线仍使用原例文页面。明确指定金蝶与 ThinkPad 时沿确认配置保留主辅角色、编码与用途，任意其他例文沿用原摄取方式。
