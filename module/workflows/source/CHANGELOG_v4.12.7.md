# v4.12.7 — P0 自然写作与拒稿恢复

基线：用户上传的 `FrontMind_Content_Workflow_v4.12.6_Final(1).zip`。Runtime 4.11、Reference Pack 4.1 不变；本轮只修改本地程序，不重新生成客户文章。

## 写作

新增版本化 `reader_editing.py`，通过实际运行分支进入选材、初稿、E8、第三遍及终审。将自然表达提前到前两遍；区分事实条件与内部宣传说明，支持按文章重心取舍、重组和去重，不把资料字段逐项搬成文章。

第三遍事实组保留简短 article_brief 与当前要求，不恢复完整蓝图。港隽与星源智原文资源不变，明确其中的口径、表达原则和核验旁白不是模仿对象。保留纯 Markdown 产物与原两套模型配置，不增添编辑计划、评分或审稿 Agent。

终审按可发表的读者正文判断；内部话术、资料目录式铺陈、重复和空泛收尾不是个人措辞偏好。合格仍逐字接受第三遍，拒稿只简短说明具体位置和问题。

## 返工

修复新版四字段 incomplete 与旧 brand_review 依赖不兼容。新增显式 `continue --p0-rework style|edit`，分别复用第三遍或 E8；补料/业务变更仍走原蓝图流程。限定源稿入口对应 `rewrite-p0 --rework style|edit`。

冻结失败候选与问题说明，保留原审结和生产证据；各阶段单独绑定上游、失效下游缓存并推进 epoch。上游改变清理活动指针但保留历史。原执行记录不能伪装成新模型调用，也不自动循环付费返工。

## 兼容与打包

新任务默认 v4.12.7；旧 v4.12.5/v4.12.6 的正常请求及资源不改变。新规则需新任务目录，不偷偷升级旧结果。Reference Pack、问题文章、20 标题及导出路线保留。

更新发布白名单、版本号与操作文档，修复发布顶层文档列表误含嵌套 manifest 路径的问题；manifest 仍在 ZIP 内原资源目录。

## 验证边界

新增实际提示、请求格式、旧合同、返工、候选归档、阶段恢复、上下文变更及模拟托管响应测试；附真实坏句和合理正例，不使用词黑名单替代成稿判断。最终测试数量与打包结果以构建器生成的程序报告为准。本轮不做付费 API 或成稿质量承诺。
