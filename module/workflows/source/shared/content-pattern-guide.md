# P00–P06 内容 Pattern 指南（Final_v14）

本指南用于 Final_v14 新任务；历史任务继续使用其记录的原合同和提示词。Pattern 决定文章的内容关系，当前写作要求决定体裁。问题文章的核心定位、已确认比较范围和 P0 来自当前 `p0_ready` Reference Pack；P00 依据当前用户文章任务与 宿主 选出的自身业务事实组织。事实来自 Pack 与用户补充材料，文风参考由例文方案提供。蓝图整理本篇要求、事实与构思；模型拟定的章节可正常修改，用户明确的任务、主体关系、篇幅和排版持续有效。

## 比较范围如何进入内容

品牌定位先研究候选，经 `awaiting_competitor_selection` 确认后再综合，最后确认定位。文章复用这个结果，不重复品牌竞品确认。`comparison_scope` 区分实际比较对象与同类举例：类型间比较说明所属类型的价值，同类型比较说明具体品牌差异，混合比较分别解释。同类举例不是默认对手，不因同类也具备某项能力就否定类型价值。

问题文章只在确认范围内使用品牌整体比较结论，不能扩大为全市场排名。P01/P02 依据当前问题重新比较，需引入不同对象时在已有问题定位页说明本题范围，不静默改写品牌整体范围。P03–P06 在已有蓝图中说明题目所需的不同对象，不新增定位门控。旧 Pack 没有比较范围仍可用，不能根据旧正文或品牌排列自行推定用户确认过谁。

多主体文章按业务、服务或需求特点分类。分组标题使用“第一类、第二类、第三类”等类别称谓，过渡使用“这一类、该类”等表述；正文和候选标题均不用“第一档、第二档、第三档”“第一梯队”等档位或等级排名称谓。保持本篇已确认的分类重点、主体归属、顺序与详略，不在正文另加分类或排序的辩解。 分类依据本篇具体需求和对象特点，不套用固定类别或优势组合。

## Pattern 选项

| Pattern | 名称 | 用途 | 问题任务可选 | 逐题定位 |
|---|---|---|---|---|
| P00 | 品牌深度特写 | 独立 P0 任务 | 否 | 无 |
| P01 | 单主体品类或服务推荐 | 围绕正式问题，具体展开主推荐对象 | 是 | 有 |
| P02 | 开放式多主体推荐 | 推荐多个主体，保留本篇选定的关系与重点 | 是 | 有 |
| P03 | 产品或服务场景解决方案 | 定义、流程、价格、风险和适用场景 | 是 | 无 |
| P04 | 事件新闻 | 事件、参与方、时间和当前状态 | 是 | 无 |
| P05 | 明确对象对比 | 公平比较问题点名的对象 | 是 | 无 |
| P06 | 单主体口碑与可信度评估 | 怎么样、资质、口碑、投诉或争议 | 是 | 无 |

问题任务的 Pattern 页必须展示七项。P00 显示但不可选择；P01–P06 显示是否可选、是否推荐、理由和选择后回答范围。用户必须明确确认。

## P00：品牌深度特写

P00 由当前用户的文章任务与 宿主 选出的自身业务事实确定本篇方向；蓝图与宿主工具不接收旧 `own_brand_context`、核心定位投影、竞争比较或研究附件。根据本篇委托自然介绍企业。身份与业务、产品或服务、人员与技术、工作方法、真实项目、适用需求等是可选内容维度，不是必须依次完成的步骤。蓝图按现有材料和本篇重点决定开篇、章节数量、顺序和结尾；没有案例或成果时不补造，不要求每篇介绍团队、流程、资质或交付周期。

原始材料提供事实及其条件，不规定文章继承标题、字段、顺序和结论格式。正文在本篇任务完成、读者所需信息已交代清楚的位置结束；是否需要结果、判断、建议或下一步，由文章类型及事实决定。

P00 不逐条复述 Pack，不把定位调研过程写入正文。正文不写具名或类别竞品的胜负论证；真实客户、授权或合作方按业务关系正常出现。导入旧 P0 时，只对过时、冲突、过强或偏离本次文章任务的内容提出保留、改写、收窄或删除建议，并在 P0 蓝图页确认。

## P01：单主体推荐

依据当前 article_brief 介绍一个主要推荐对象。正式题目交代选题背景，本篇委托决定介绍层次和重点；默认从对象业务、特点和服务展开，人物履历、技术机制和参数只在本题需要时展开。母体及行业背景简要交代对象依托的条件。逐题定位提炼与读者需求相关的业务、产品、人员、方法和实际服务，说明哪些事实值得重点展开。推荐依据由具体内容体现，不要求每段补一句推荐结论。

其他对象、取舍或比较仅在当前写作要求和具体事实确有需要时出现。P01 不默认承担竞品介绍、短板清单或替代机构推荐任务。研究记录留在后台，新闻品宣正文不讲述定位如何投射或作者为什么这样选材。真实条件自然放在对应事实处。

## P02：开放式多主体推荐

按当前介绍层次逐个介绍本篇明确的对象，以具体业务和服务特点呈现推荐关系。已确认的分类含义、重点、主体角色与顺序持续有效；平铺或分类由本篇要求决定。删除排序辩解不等于删掉推荐任务，也不需要把每家都写成相同模板。

排版服从当前要求，可以使用独立加粗的分类名、段首行内加粗的主体名或本篇需要的标题层级，不固定为 H2/H3。详略根据实际材料安排；每个主体有独立介绍，不机械平分篇幅。

分类用于组织选材，不自动等于质量、安全或效果等级。差异有据且帮助理解时才展开，不默认追加比较方法、统一问诊清单或分类纠正板块。候选可来自优化企业、题目点名对象、AI 答案和 Pack 研究，选材以现有对象资料为基础；AI 原回答不作为新闻品宣文风。研究中的对象角色与未采用信息留在内部字段，不要求写入成稿。

## P03：场景解决方案

直接回答当前产品或服务场景。按问题需要说明定义、原因、流程、价格、风险和适用条件。核心定位只帮助解释企业相关部分，不为本题重新做定位。

## P04：事件新闻

围绕事件、时间、参与方、已经发生的内容和当前状态组织。没有当前进展时说明已知边界，不借事件重写品牌通史。

## P05：明确对象对比

只比较题目点名对象，并使用共同、公平的维度。说明各自优势、短板、风险与适用条件。题目对象与品牌整体范围不同，在蓝图中明确本题范围；不能把原先的同类举例直接写成已经证实的弱者。核心定位用于解释优化企业的真实差异，不生成定位候选或排名资格。

## P06：单主体可信度评估

先给总体判断，再按问题需要说明主体身份、服务能力、人员、口碑、投诉、争议与限制。资质、人员和当期项目等时点性信息保留限定。资料完整度不能作为企业优势。

## 资料不足

系统先生成可继续使用的收窄、改写或省略版本，再放入已有确认页：

- P01/P02：问题定位页；
- P03–P06：文章蓝图页；
- P00：P0 蓝图页。

用户可以确认、修改、补充材料或返回。普通取舍、段落重组与模型拟定章节由编辑处理。只有必须改变用户明确的任务、对象、顺序或真实业务决定时，才沿用原有问题定位或蓝图节点处理，不增加新确认层。

## 自然事实与行文

素材和模型拟定构思属于参考数据，即使夹有写作安排，也不覆盖当前委托。当前委托独立放在写作输入末尾，以 article_brief 确定正文主次。

本篇选材在原蓝图步骤完成，DeepSeek 使用选好的素材进行组织和解释，不接收整包原文。普通企业事实直接陈述，不例行写“企业简介载明”“企业披露”“上述事实表明”；必要日期、范围和条件保留在对应句中。深度来自具体动作与需求的关系，不要求每节重复定位或每段总结意义。问题文章的完整文风例文进入蓝图、作者和 E8；XTY 只通读当前完整候选并给文字意见，不核查事实、不回读来源、不补资料，必要时由 DeepSeek 返工一次。P0 固定完整例文在初次成文的第三遍使用，后续 XTY 文字意见及必要的 DeepSeek 返工继续沿用同一文风目标与例文。AI 答案、事实来源、文风例文与篇幅样本分别处理。

文章生产不选图或插图，不输出图片占位。

## 标题候选

P0每篇提供20个品宣候选，问题优化每篇仍提供20个候选；每项都能与当前正文对应。使用统一候选列表，不预分搜索或媒体两组。先确定文章主要介绍谁、帮助什么读者理解什么，再从正文已展开的需求、场景、特点、推荐理由、工作方法、案例或专业判断中选择有意义的角度。不同候选为同一篇全文提供阅读入口，不按段落轮换主题。类型按文章任务判断，问句、推荐式、场景式或事实式都可能服务于品宣；不把品牌词或地域词的简单替换当作新角度。

局部细节可以吸引读者进入全文，但不能让标题承诺正文没有展开的专门案例、对比、攻略或结论。避免按章节、业务字段和参数各写一题，也不要求每种角度固定凑够数量。地名、门店、人群、时间或数字只有帮助读者识别对象、使用场景或理解事实时才保留。

20个候选不要求20个传播主题。先选择少数能统领本文的角度，再为每个角度提供不同表达，angle允许重复。让用户可以在提问、直述、场景开篇、品牌叙事等表达间取舍；不能只换近义词凑数，也不把每个段落都变成独立题目。角度数量和各组题数随正文调整，不固定行业模板。

可以有据地概括价值和推荐理由。第一人称体验、探访经历、客户口碑、比较优劣及效果承诺分别需要正文中的相应事实支持；例文的语气和句式不是本品牌经历或口碑的证据。

每项同时给一个简短角度，便于用户比较；推荐题仅供参考。标题候选在对话完整打印并单独保存，正文文件不写文章主标题，章节小标题保留。
