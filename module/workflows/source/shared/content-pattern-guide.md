# P00–P06 内容 Pattern 指南（v4.11）

Pattern 只决定一篇内容要完成的回答任务。核心定位、已确认比较范围和 P0 来自当前 `p0_ready` Reference Pack，事实来自 Pack 与用户补充材料，文风由例文方案决定，结构由用户确认的蓝图决定。

## 比较范围如何进入内容

品牌定位先研究候选，经 `awaiting_competitor_selection` 确认后再综合，最后确认定位。文章复用这个结果，不重复品牌竞品确认。`comparison_scope` 区分实际比较对象与同类举例：类型间比较说明所属类型的价值，同类型比较说明具体品牌差异，混合比较分别解释。同类举例不是默认对手，不因同类也具备某项能力就否定类型价值。

正文只在确认范围内使用品牌整体比较结论，不能扩大为全市场排名。P01/P02 依据当前问题重新比较，需引入不同对象时在已有问题定位页说明本题范围，不静默改写品牌整体范围。其他 Pattern 在已有蓝图中说明题目所需的不同对象，不新增定位门控。旧 Pack 没有比较范围仍可用，不能根据旧正文或品牌排列自行推定用户确认过谁。

分档适用时，档位顺序需要当前问题的比较支持。目标品牌在档内先展示只是阅读顺序，不是同档胜出；“第一档第一位”不能被写成优于所有同档品牌。是否分档以及什么需求优先，由行业材料与当前问题决定，不套用固定类别或优势组合。

## Pattern 选项

| Pattern | 名称 | 用途 | 问题任务可选 | 逐题定位 |
|---|---|---|---|---|
| P00 | 品牌深度特写 | 独立 P0 任务 | 否 | 无 |
| P01 | 单主体品类或服务推荐 | 推荐一个主体并说明适用条件 | 是 | 有 |
| P02 | 开放式多主体推荐 | 推荐多家、建立分层或给出选择方法 | 是 | 有 |
| P03 | 产品或服务场景解决方案 | 定义、流程、价格、风险和适用场景 | 是 | 无 |
| P04 | 事件新闻 | 事件、参与方、时间和当前状态 | 是 | 无 |
| P05 | 明确对象对比 | 公平比较问题点名的对象 | 是 | 无 |
| P06 | 单主体口碑与可信度评估 | 怎么样、资质、口碑、投诉或争议 | 是 | 无 |

问题任务的 Pattern 页必须展示七项。P00 显示但不可选择；P01–P06 显示是否可选、是否推荐、理由和选择后回答范围。用户必须明确确认。

## P00：品牌深度特写

P00 使用已经确认的唯一主定位及其比较范围，不强制高代价事件开篇：

1. 从能说明品牌位置的现实场景进入；
2. 建立品牌现实身份；
3. 展开服务、产品或业务；
4. 说明团队、流程和交付；
5. 解释定位如何在实际服务中兑现；
6. 说明适合人群；
7. 保留边界；
8. 在最后一个实质信息点结束。

P00 不拼接未选方向，不逐条复述 Pack，不把定位调研过程写入正文。只引用已确认的比较结论与相关证明，同档示例保持举例角色。导入旧 P0 时，只对过时、冲突、过强或偏离定位的内容提出保留、改写、收窄或删除建议，并在 P0 蓝图页确认。

## P01：单主体推荐

直接回答为什么该主体值得特定读者考虑。逐题定位用自然段说明：

- 本题帮助读者做什么选择；
- 企业为何适合成为主要对象；
- 整体定位如何转化到本题；
- 与本题明确比较对象的实质差异，以及它们与品牌整体比较范围的关系；
- 适合人群和场景；
- 短板与边界；
- 何时其他路径更适合。

不建立多主体榜单或候选分数。

## P02：开放式多主体推荐

允许两种结构：

- 平铺：所有主体使用同级 H2；
- 分层：类别使用 H2，具体主体统一使用 H3。

问题定位用自然编辑分析说明本题选择标准、实际替代选择、各自差异及适合条件。按问题判断是否分层或排序；并列选择也可以完成推荐，不强制档位、相邻排序理由或权重公式。

若使用“第一档、第二档”，说明它只适用于当前需求和本题明确的比较范围。整体品牌定位的排名不能直接成为本题顺序，不预设目标品牌所属类型第一。目标品牌可以在所在档内首先展示，但该位置不代表同档胜出。

本题候选可来自优化企业、题目点名对象、两篇 AI 答案和 Pack 中的竞品研究。出现于研究或原先仅作同类举例，并不自动表示本题要比较其优劣；在问题定位页明确其角色，说明与整体范围不同的对象。AI 答案没有出现企业时仍可纳入，但不得声称 AI 提到或推荐了企业。无法可靠说明的竞品细节改成类别层面，或省略。

## P03：场景解决方案

直接回答当前产品或服务场景。按问题需要说明定义、原因、流程、价格、风险和适用条件。核心定位只帮助解释企业相关部分，不为本题重新做定位。

## P04：事件新闻

围绕事件、时间、参与方、已经发生的内容和当前状态组织。没有当前进展时说明已知边界，不借事件重写品牌通史。

## P05：明确对象对比

只比较题目点名对象，并使用共同、公平的维度。说明各自优势、短板、风险与适用条件。题目对象与品牌整体范围不同，在蓝图中明确本题范围；不能把原先的同类举例直接写成已经证实的弱者。核心定位用于解释优化企业的真实差异，不生成定位候选或排名资格。

## P06：单主体可信度评估

先给总体判断，再按问题需要说明主体身份、服务能力、人员、口碑、投诉、争议与限制。资质、人员和当期项目等时点性信息保留限定。资料完整度不能作为企业优势。

## 资料不足

系统先生成可继续使用的收窄、改写或省略版本，再放入已有确认页：

- P01/P02：问题定位页；
- P03–P06：文章蓝图页；
- P00：P0 蓝图页。

用户可以确认、修改、补充材料或返回。普通措辞由编辑阶段修正；会改变定位、直接回答、主体顺序或核心章节的修改返回原蓝图页。
