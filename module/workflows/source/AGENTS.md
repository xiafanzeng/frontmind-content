# FrontMind 通用 Workflow v16.8

当前用户委托决定品牌、问题、体裁、范围和篇幅。历史案例及旧授权不构成当前执行要求。通用入口参见README；不要把客户案例写死到新Prompt。

新P01至P06使用frontmind-natural-prose/16.5。统一编辑准备、蓝图、初稿、全文编辑与文风验读，保留六类各自的叙述任务。P0保留专用正文阶段，新任务沿用选用事实约束；历史正文合同保持原状；新标题使用frontmind-category-titles/4，不改写历史冻结请求、结果和恢复策略。

素材直接介绍对象与事件，蓝图用正向描述安排内容与主次。完整文风例文进入作者、全文编辑和返工；文章池仅用于构思。编辑不传蓝图章节脚本，拥有改导语、整段、整节、标题与结尾的权限。允许口语、有限重复及不完全工整，实际好读的表达保留。

P01—P06 的文风验读只提交needs_revision/comments，以当前完整候选的阅读效果判断是否可发布。不做事实审计、逐项纠错报告、评分、禁词命中或外部检测。需要修改时从最近完整失败稿继续编辑，修改后再次全文验读；通过后原样使用实际正文。不要把离线程序测试、格式或字数通过写成文风通过。

默认篇幅按信息量决定，estimated_length与例文长度仅为建议。显式body_character_range才是硬性范围。删重复不等量补空话。正常场景、用途与价值表达属于写作空间，人物经历、数字、引语等具体内容使用本篇素材。

P01单主体；P02默认自动选定综合企业实力明显更强且本题同期AI声量更高的两家竞品，主品牌先，名单贯穿写作。合格对象按平台等权提及率排序，不再例行竞品确认；用户明确指定两家优先。不足先补研，再请求必要输入。P03至P06不新增逐题定位确认。

新P0—P06每篇统一10个标题，前5个style=formal为正式标题组、后5个style=scenario为场景卖点组。formal保留各篇体裁：P0正式品牌介绍，P01/P02正式推荐，P03解决方案，P04事件新闻，P05点名对比，P06评价；后5个从同一正文的场景或卖点切入，不改写成另一选题。P0十项均包含当前品牌名；P01/P02默认不出现品牌或机构专名，用户明确标题要求优先；P03—P06沿用当前选题的对象命名，新闻、点名对比和“怎么样”评价保留必要主体名字。标题独立交付，推荐项不回填正文。

十题提供不同阅读入口，每题抓一个重心，避免正文高频词洗牌。每项含title、angle、style及1—2个建议投放位组成的usage_hint数组；候选与终稿保留后台title_notes。素材来自最终正文与明确title_ammo_extra，保留原句、来源和正文覆盖标记；不从Prompt指令提取产品数字，不拼机构背书，不自动扩写正文。标题长度、并列、相近换序与机制套话仅作为编辑提示，编辑可整组重拟；不设数字配额、禁词清零、分数或发布门控。

v1—v3及无标记20项旧任务按冻结策略恢复；v3规则仍在writing_context_v14.py，v4使用独立title_editorial_v168.py；已完成P0—P06只有显式--title-edits才升级到v4并重生成标题与导出，正文及其合同不变。

新单问题任务复用同题同期两个不同AI平台完整答案与逐条信源。缺失停在原输入页；支持XLSX/CSV/JSON及source-period。文章池打印Top20并提供完整池，按引用频次排序，原例文页选择1—2篇或none，全文失败可补交。已确认定位匹配题目、品牌、Pattern及适用名单后进入准备与蓝图；用户要求优先。

过程展示保存实际步骤、稿件和编辑结果。网站执行入口对已结束的真实步骤和工具回执生成简体中文公开摘要，直接显示并渲染Markdown；状态查询和历史读取只读已保存摘要。模型与配置保留现有值，DeepSeek默认high，历史重试沿用原配置。原资料和历史生成记录保留，新增真实样例独立标识。

修改Prompt与入口时同步README、START_HERE及总控skill。公开发行只包含通用源码、合成测试及授权公共资源；客户原件、实际调用记录和客户样稿独立保存在私有交付目录。接收端执行离线测试与干净解压入口检查，如实区分离线验证和经用户授权的真实模型写作。

新建 P0 在初稿、E8、文风编辑、全文编辑意见与返工中传递同一份选用事实。全文编辑同时检查稿件与材料的一致性，扩写意见须指向材料已有内容；作者不把通用方法写成企业实际采用的步骤、协作、服务或效果。任务以 `p0_selected_facts_mode=selected-facts-v1` 冻结该输入，历史无标记请求保持原文。现有阶段、模型和一次编辑返工流程保留。
