# FrontMind v4.12.6 执行手册

## 本次唯一改动方向

第三遍作者专注成文，宿主最后简单验读。以v4.12.5为基线，不替换模型、不增加阶段、不重新设计资料包、定位或问题文章业务。

## v4.12.6 当前P0合同

新建P0使用 `frontmind-p0-style/4.12.6`。宿主仍为智谱原生 Managed Agents `glm-5.3/max`；作者仍为 DeepSeek `deepseek-v4-pro`，开启思考，`max`。按篇选材与蓝图、初稿、E8不读取品宣例文；只有第三遍接收 **E8全文＋本篇事实（含必要条件和当前明确要求）＋星源智与港隽两篇完整原文**，直接返回完整Markdown正文。

第三遍不再提交编辑计划、修改说明、自评、例文对照或遗留问题报告。程序仅将实际正文封装为 `article_markdown` 存档；没有补造审核字段。Managed Agent最后简单通读：合格逐字保留第三遍正文，有影响交付的具体问题才简短说明并停止；不重写、不评分、不生成复杂报告。20个标题及标题编辑、正文无主标题导出、资料包业务和问题文章路径保持不变。

生产仍必须实际调用上述两套模型，不允许入口AI代写或静默换模型。历史合同仅用于旧任务，不把旧输出改记为新调用；需要新写法请新建任务。具体接口与复用规则以《FrontMind_执行手册_v4.12.6.md》为准。

## 第三遍实际输入与输出

三组输入为：E8完整稿；本篇选定事实（含必要条件及当前明确要求）；星源智、港隽两篇完整原始例文。不同阶段的完整蓝图和后台研究仍保存，但不作为额外大块输入重复发送。例文的写法分析指南也不进入第三遍。

系统提示要求直接介绍企业、业务、方法和真实项目，允许重组段落与详略，准确自然的内容可以保留。不追求每段升华、哲理化点评或金句，也不把段落改成逐项定义。事实、历史时间、范围和已确认业务边界保持不变。

作者只返回完整Markdown文章，首行一个H1、小节H2。没有JSON外壳、编辑计划、修改说明、自评、例文对照或额外问题报告。响应适配器把原文封装进内部`article_markdown`字段，仅供已有存档、标题、导出代码消费；不生成额外作者判断。

## 简单验读

Managed Agent读取唯一第三遍候选、本篇事实与当前要求，检查影响交付的明显事实错误、重要遗漏、重复、读不通和后台口吻。只在有具体事实疑问时回读原件，不重新加载例文、重做市场研究或提交逐项评分。

结果沿用四个基本字段，避免另造一套状态接口：

```json
{"outcome":"accepted","article_markdown":"第三遍完整原文","editorial_notes":[],"reason":""}
```

确有问题时使用`incomplete`，正文及修改说明为空，reason简短说明问题；只有必须改变用户已确认业务决定才使用`requires_blueprint_reconfirmation`。`revised`不是本版终审选项。终稿和第三遍正文必须逐字一致，不能由宿主或入口AI重写后再冒充作者原文。

## 启动与限定源稿重写

```bash
./scripts/frontmind preflight
./scripts/frontmind
./scripts/frontmind rewrite-p0 --live --run-dir runs/yihang_v4.12.6
```

前两条保留原业务入口；第三条只用于已明确授权的源稿重写。自定义用法：

```bash
./scripts/frontmind rewrite-p0 --live --source /absolute/source.docx --brand '完整品牌名' --requirements-file /absolute/requirements.md --run-dir /absolute/new-job
```

原包两套凭据配置保留，预检不联网。生产动作仍调用真实Managed Agents和DeepSeek Pro；网络错误、截断、错误模型和空正文停止执行，不允许入口模型补写。

## 版本与恢复

新P0使用4.12.6合同。旧任务保留其已保存合同，不补造新的调用，不自动改写过去成稿。新旧第三遍的Prompt、响应格式和正文合同均进入缓存校验，不能串用；要用新行为写同一品牌，请新建任务或限定重写目录。只更换运行包不会把旧任务自动标记为新协议。

两篇例文和指纹沿用4.12.5，资源清单版本仍为4.12.5；这是刻意保留的例文选择版本。星源智原文在第三遍按原有方式取得和核对，港隽原文来自用户提供文本。保留原始快照；正文不可用时不得使用摘要或合成内容代替。

失败后的显式重试沿用现有命令。成功缓存重新核验原始响应；普通继续不自动循环付费重试。第三遍失败不回退E8，终审不通过不导出。标题只使用已经验读通过的正文，仍单独输出20项和标题编辑结果；Word正文不加主标题。

## 验证口径

程序测试采用合成正文与模拟流，检查传递、解析、恢复、版本隔离、真实工具接口schema和导出。它们不是客户品宣样本，也不证明真实API已经联调成功。本轮未发起付费API生成；新任务的最终内容质量仍由实际文章判断，不承诺每次自动达到例文水平。
